## 1. What the top-left expanse is, from the plan's water mask: LAND
`CityA2Raster.is_water / is_river` over the A2 raster (the 165 x 165 city rect) contain ONLY river cells in the plan frame (plan: 17 river, 0 other water; seed 3: 19 river, 0 other). Terrain (coarse rect -200..205, 405 x 405 lots) has no cell at or below 0 BU in the top-left expanse; the only cells with terrain at or below 0 that are not plan water are the 45 (seed 3: 43) cells in the plan's bottom edge (magenta in the overlay), which render as the blue sea strip in the plan's south. So by both the plan's mask and its terrain, the top-left expanse is land beyond the city rect, not sea. The "Sea mesh extent" is exactly those south cells (the water mesh is built from the terrain's low cells).
Why it used to look like navy sea (my finding, for the designer): the OuterLand mesh is tagged with the water class (`outer_class() = water_class()`; code comment: the plates grade the land past the city as deep water), so the realism grade (g1 level 3) painted it as navy sea. Since r28 the raid post runs at grade level 0, which skips that class paint, so the real land colour shows. It was never water in the plan data.
