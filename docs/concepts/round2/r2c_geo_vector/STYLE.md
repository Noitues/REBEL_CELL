# r2c_geo_vector: triangulated vector poster

**Reference translation.** The reference cat is made only of flat, outline-free triangles on a smooth gradient. Light shows only in each triangle's tone, drawn from one warm-to-deep ramp. I kept those rules and changed the subject. Every surface (building faces, streets, the slab, spinner slices, cards, buttons, the vendor) is a jittered grid split into triangles. Each triangle's colour is picked from a ramp as *light + surface gradient + seeded jitter*, with an occasional tone "flip" that gives the reference its shattered-glass sparkle. The backgrounds stay smooth gradients with dark edges, like the reference. Neon is never a glow. It shows up as saturated triangle clusters: lit window bands, blade signs, the billboard eye, the visor. The searchlights are the one translucent element, and even they are built from triangles.

**Palette.** Day uses the reference ramp (plum `#2b0a24` → crimson `#b8243a` → orange `#f07a3a` → cream `#f9d98e`), with teal glass towers (`#1f6170` → `#a3dcc3`) set against a teal/khaki sky. Night swaps each building family for an indigo ramp (`#05041a` → `#6e2e7e`) and lights it with magenta `#e0288a`, cyan `#18c0e0`, amber `#f09018` and lime clusters. High suspicion collapses everything to a single oxblood ramp (`#040103` → `#98283a`) with alarm-red windows, beacons, helicopters and drones. The UI keeps one key throughout: gold path, cyan "you are here", magenta target, lime shop and red boss. Cards and slices use the same ramps: attack is crimson, guard teal, hack magenta and charge gold.

**Technique.** The whole thing is pure Python and Pillow, with no Blender. My own orthographic camera (azimuth 24°, elevation 38°) projects a seeded city model, which is drawn back to front on a 2× canvas and then Lanczos-downsampled. Each face is lit with Lambert shading, which sets the base tone on its ramp. Geometry and colour draw on separate seeded streams, so day, night and suspicion share every triangle. Run `python scripts/render_all.py` to rebuild everything (about 10 s).

**In Godot (2D/2.5D).** Bake the city as layered sprites or as a `Polygon2D`/`MeshInstance2D` built from the same triangle lists. Store the per-triangle ramp coordinate *t* as vertex colour or UV, and let a small shader map *t* through a gradient texture per theme. Day, night and suspicion then become one shared mesh with a ramp swap, and windows light up by switching their ramp. Spinner slices can be generated at runtime as polar-grid triangle fans, so slice size in ticks stays data-driven. Cards and buttons can be static faceted textures with text laid over them. The nav overlay (gold ribbons, arrow chains and crystal pins) is a separate `CanvasLayer`, so it always reads above the buildings.
