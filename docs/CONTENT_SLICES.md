# Content Slices — running list

Two kinds of content work (designer ruling 2026-09-24):

- **Vertical slices** make the loop complete end to end for one class, one corporation
  and the 10-Site Grid. They come first (milestones M0–M4).
- **Horizontal slices** add breadth to a system that already works (more slices in the
  shop, more cards, more classes…). They wait until the vertical slice is done, unless a
  minimal version is needed for the loop to function (marked *minimal*).

Status: `done` / `minimal` / `todo` / `M<n>` (planned for that milestone).
