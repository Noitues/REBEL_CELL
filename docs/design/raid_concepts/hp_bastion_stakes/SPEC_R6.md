# HP: Bastion + Stakes (round 6)

H's persistent fortress with P's node jobs and survivors who rejoin. Code: `tools/raid_concepts/concept_hp6_merged.py`.
Every rule is a **designer decision**.

## Rules
H and P combined. The fortress forecast in the shop runs the carry rule, so a line that lets threats live shows the
later raids growing.

On campaign 1:
- **Home line:** kills everything, so its rosters stay 2 / 3 / 4. Bank −1, 15, 34.
- **Forward line:** its survivors stack up, so rosters grow 2 / 4 / 8. Bank −1, −1, −11.

## Frames
0. The campaign leg with the jobs.
1. The shop and the fortress forecast under the carry rule.
2. Raid 1 forecast (survivors who would rejoin).
3. Aftermath (the next roster, survivors marked).
4. Visit 2.
5. The record.
