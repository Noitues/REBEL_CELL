## Acceptance
1. A default slice matches pre-N20 golden numbers.
2. `hits=3`, base 5, no block: three hit events of 5 (total 15). Each hit meets BLOCK/SHIELD separately: BLOCK 7 → 5 absorbed, 2 through, then 5, 5 (12 HP lost).
3. `hits_per_target_status`: hits = max(1, count of target-wheel slices with status × per-stack). Three CORRUPTED slices at 2 damage → 3 hits of 2. Zero → 1 hit.
4. `perfect_multiplier` applies on PERFECT only (base 10 → 40). GOOD and WEAK unchanged; WEAK keeps 0.5×.
5. `pierce=true` ignores BLOCK and SHIELD; SANDBOX charges (Q39) and bodyguard satellites still intercept.
6. Rider order, documented in the `##` comment on `_resolve_pointer`: tier output → perfect_multiplier → per-hit scaling → absorption.
7. `validate()` rejects `hits < 1` or `> MAX_HITS`, `perfect_multiplier <= 0`, status count with status NONE, riders on non-damage slices; each with a named reason.
8. Preview uses the same code path; per-hit breakdown equals resolve results for 1–3 pointers.
9. Enemy flat rider damage is scaled by tier damage factor (R2); percent amounts are not.
10. Seeded replay gives an identical state hash; riders use no RNG.
