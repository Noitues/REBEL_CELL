## Acceptance
1. Each twin is pure RefCounted: no Node, no randomness outside `RngService` streams passed in, ties broken by id.
2. For at least 10 fixture seeds, street and HQ, derive JSON is byte-identical to the Python reference (canonical text compare); failure prints the first differing path.
3. Poses (overview, decision, hover, dive), framing and occlusion match the reference after rounding to 1e-4.
4. Rig follows AD item 4 (0 = north, clockwise). Z 1.0 s and step 0.9 s are read from config.
5. Pixel-parity test checks Godot `frustum_offset` against `shift_x`/`shift_y` as fractions of frame width (AD item 5); tolerance is a config value.
6. The dress reader loads `dress_<run>.json` v1, accepts rest, workshop and cache, and rejects an unknown `version` or room kind (AD item 19) with a named error. Ported last, in its own commit.
7. Deriving twice for the same seed gives identical bytes.
8. New tests are in the manifest, tier `fast`, and mapped by `select_tests.py`.
