# N7: Block nudge / respin locks

- **Goal**
  - Add per-wheel locks `nudge_locked` / `respin_locked` as {source, turns_left}, set by LOCK_NUDGE / LOCK_RESPIN effects.
  - A locked action is refused by `validate_action` with a named reason and costs nothing. A lock overlay shows on the wheel.
  - Turn lifecycle per Q31: every lock is removed at end of turn, except Freeze.
- **Base / tag**: `<BASE_SHA>` / `<TEMP_TAG>`
- **Agent type and lane**: fix-rules, Sonnet. No Opus: no RNG, save-format or damage-order change. The lock fields join the state hash and the save as plain data.
- **Depends on**: N6 (optional). Listeners may set locks if N6 has landed; otherwise only slice and hub effects set them.

## Acceptance
1. A new combat has no locks on any wheel. Locks are per wheel and independent.
2. LOCK_NUDGE blocks the free nudge and paid nudges on that wheel. A refused nudge returns `ok=false`, reason `NUDGE_LOCKED`, the source id in the detail, and spends 0 RAM. The free nudge flag is unchanged.
3. Nudge cards still work under a nudge lock. Spin, Flip and Freeze are unaffected.
4. LOCK_RESPIN blocks the Respin card and the 4 RAM own-wheel respin (reason `RESPIN_LOCKED`, 0 RAM spent). The start-of-turn respin is never blocked.
5. At end of turn all locks are cleared. Freeze is the only effect that persists past it, and is removed after the initial spin it prevented (Q31).
6. Two locks on one wheel merge: the larger `turns_left` wins (not the sum), and sources are kept sorted by content id. `turns` < 1 is rejected at validation and leaves no lock.
7. A lock survives a boss phase swap via `_apply_wheel_override`. It is cleared at combat end.
8. The state hash differs with vs without a lock. The save round trip preserves it. A save without lock fields loads with no locks (default).
9. The preview shows the refusal reason before commit, and a staged lock effect shows as "locked" in the preview. Preview equals result on 50 seeded cases.
10. The overlay shows on the locked wheel and the click-refusal toast shows the reason string through TextDb. US English, text 1.0.
