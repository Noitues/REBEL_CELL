# test plan: N17 Event wheel

## 1. What is a rule here
Rule-bearing (unit tests, per CLAUDE.md rule 6):
- `EventWheelData` (new data file): `validate()` and its fields (outcome slices, `nudge_budget`, `extra_nudge_cost`).
- The event-wheel session logic in `netrun_session`: open, stage a nudge, extra-nudge cost, lock-in, outcome resolution, and the `events` RNG draw at a checkpoint.
- The outcome-resolution function, which should be pure: (wheel, rotation, pointer tick) → outcome slice and tier. It is the same math as `WheelMath` (and N12 `size_ticks` when present).
- Save/restore of a pending event-wheel state, and the state hash used by replay.

View glue (one flow test only, no unit tests):
- The event page built on `wheel_kit.gd`: layout, labels, button wiring, chips.

## 3. Cases

**test_event_wheel_data.gd**
1. `test_valid_wheel_passes_validate`: a 6-slice wheel, sizes sum to 30, budget 1, cost 1 → no errors.
2. `test_empty_outcomes_rejected`: 0 slices → error "event_wheel: no outcome slices".
3. `test_size_sum_not_30_rejected`: sizes sum to 29 → error "sizes must sum to 30". Needs N12.
4. `test_negative_budget_rejected`: budget −1 → error "nudge_budget < 0".
5. `test_negative_extra_cost_rejected`: cost −1 → named error.
6. `test_duplicate_outcome_id_rejected`: two slices with one id → "duplicate outcome id".
7. `test_outcome_with_no_effect_rejected`: outcome with neither effects nor result text → error.
8. `test_zero_budget_allowed`: budget 0 is valid (pure spin, no nudges).
9. `test_without_n12_defaults_to_5_tick_slices`: `size_ticks` absent → 6×5, sum 30. This is the data-only fallback.
10. `test_ids_unique_across_registry`: ids are unique across all event wheels.

**test_event_wheel_session.gd**
1. `test_preview_equals_result`: seed 7, rotation r; the previewed outcome id equals the resolved outcome id for all 30 ticks.
2. `test_first_nudge_free_when_budget_1`: budget 1 → RAM or cost unchanged, budget 0 afterward.
3. `test_extra_nudge_costs_exact`: budget 1, `extra_nudge_cost` 2; the 2nd nudge reduces Cycles by exactly 2.
4. `test_extra_nudge_refused_when_unaffordable`: Cycles 1, cost 2 → refused with a reason string, state unchanged.
5. `test_nudge_edges_0_1_max`: budget 0, 1 and 3 give exactly that many free nudges, then a paid one.
6. `test_nudge_wraps_tick_30_to_0`: rotation 29 + 1 → 0, outcome per the slice at tick 0.
7. `test_tier_boundaries`: ticks at offset 0 / ±1 / ±2 resolve PERFECT / GOOD / WEAK, with outcome scaling per the draft. Tier only applies if the draft authors it.
8. `test_undo_restores_nudge_and_cost`: nudge then undo → the state hash equals the pre-nudge hash.
9. `test_rewind_stops_at_checkpoint`: the initial spin is a checkpoint; undo after it is refused with a reason.
10. `test_confirm_applies_outcome_once`: double-confirm applies the effects once.
11. `test_tie_break_equal_distance`: a tick exactly between two slices (a 4-tick sub-tick map, N12) → lower slice index, then content id.
12. `test_outcome_condition_filters`: an outcome gated on a missing condition is excluded and the pick is deterministic.

**test_event_wheel_rng.gd**
1. `test_spin_uses_events_stream_only`: the draw count on `events` is +1; the other streams are unchanged.
2. `test_no_global_randi`: a source scan of the new files finds no `randi(` or `randf(`.
3. `test_same_seed_same_inputs_same_hash`: two runs, seed 42, inputs [nudge, confirm] → equal hashes.
4. `test_different_seed_differs`: seeds 42 vs 43 → the initial rotation differs for at least one wheel.
5. `test_save_load_mid_wheel_round_trip`: save after the spin and 1 nudge, load → identical state; no re-roll.
6. `test_reload_cannot_reroll`: save → quit → load → the same rotation (checkpoint persisted).
7. `test_stream_position_checkpointed`: the stream state after load equals the state before saving.
8. `test_old_save_without_event_wheel_loads`: a save with no pending wheel loads with the field null. No save version bump expected; if it changes, add a migration test.

**test_event_wheel_content.gd**
1. `test_all_event_wheels_validate`: iterate the registry; fail messages list the ids.
2. `test_every_wheel_has_at_most_one_hard_loss_slice`: guards the cap on severe outcomes, assuming the drafts agree.
3. `test_us_english_strings`: text in the wheels passes the existing us_english check.

**test_event_wheel_page.gd**
1. `test_event_node_opens_wheel_page`: a Terminal event with a wheel shows the page.
2. `test_nudge_button_disabled_when_unaffordable`: shows the reason.
3. `test_confirm_closes_page_and_applies_reward`: after confirm, the run state changes and the map is back.
4. `test_keyboard_only_flow`: Left/Right nudge, Enter confirm (mouse and keyboard scope).

**test_event_wheel_sweep.gd** (full)
1. `test_500_seeds_all_wheels_terminate`: each reaches an outcome; no null.
2. `test_outcome_frequency_matches_slice_size`: over 30 ticks, counts per slice equal the slice's tick count exactly.

## 6. Order
Write `test_nudge_*` and `test_preview_equals_result` first, against a minimal `EventWheelData` stub. Together they pin the budget, cost and the preview = result contract. Then `test_same_seed_same_inputs_same_hash` and `test_spin_uses_events_stream_only` before any page work.
