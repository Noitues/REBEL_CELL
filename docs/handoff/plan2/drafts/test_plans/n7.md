# test plan: N7 Block nudge / respin

## 1. What is a rule here
**Rule-bearing (unit tests):**
- `wheel_state`: the lock records `nudge_locked` / `respin_locked` as {source, turns_left}, plus tick-down, stacking, and serialization.
- `combat_resolver.validate_action`: refusals, each with a named reason code.
- `combat_resolver.start_turn`: lock expiry and the order of tick-down against the start-of-turn respin.
- LOCK_* effects in `effect_interpreter` (LOCK_NUDGE, LOCK_RESPIN): scope, duration, and interaction with resistance and Freeze.
- Replay and state hash inclusion. Save round trip of lock fields.
- `EnemyData` / `SliceData` / `EffectData` validation of LOCK_* parameters.

**View glue (one flow test only, no unit tests):** `ui/wheel` lock overlay, the refusal toast text, and disabled-button styling. The flow test checks that the overlay shows when a lock is present and that the refusal reason string appears on a refused click.

**Locked scope (decided here):**
- NUDGE lock blocks nudge actions: the free nudge and paid nudges. Cards that nudge still work. This follows the Halcyon P2 ruling "cards still work".
- RESPIN lock blocks both the card Respin and the 4 RAM own-wheel respin.
- The start-of-turn respin is never blocked (it is the random event that sets the checkpoint).
- Spin, Flip and Freeze are unaffected.

## 3. Cases
**test_wheel_locks.gd**
1. `test_new_wheel_has_no_locks`: create a combat and assert both locks are empty.
2. `test_lock_nudge_records_source_and_turns`: apply LOCK_NUDGE (source "citation", turns 1) and assert the fields.
3. `test_lock_expires_after_turns_elapse`: turns=2, call start_turn twice; the lock exists after the 1st and is gone after the 2nd.
4. `test_lock_does_not_tick_on_player_actions`: play 3 cards, assert turns_left is unchanged.
5. `test_two_sources_stack_to_max_turns_not_sum`: turns 1 then 3 → 3, and the source list keeps both ids sorted by content id.
6. `test_lock_on_own_wheel_and_enemy_wheel_independent`: lock one wheel; the other is unaffected.
7. `test_turns_zero_is_rejected_noop`: LOCK with turns=0 leaves no lock.
8. `test_lock_survives_phase_change`: a boss phase swap via `_apply_wheel_override` keeps the lock (the same R6 spirit as statuses).
9. `test_lock_cleared_on_combat_end`: nothing leaks into the next combat.
10. `test_state_hash_changes_with_lock`: hash differs with vs without the lock.

**test_lock_validation.gd**
1. `test_nudge_refused_when_locked_reason_nudge_locked`: validate_action(NUDGE) returns ok=false, reason `NUDGE_LOCKED`, and the source id is in the detail.
2. `test_refused_nudge_costs_no_ram_and_keeps_free_nudge`: RAM and the free-nudge flag are unchanged after the refusal.
3. `test_card_nudge_allowed_under_nudge_lock`: a nudge card plays and the wheel moves.
4. `test_respin_card_refused_under_respin_lock`: reason `RESPIN_LOCKED`.
5. `test_ram_respin_refused_under_respin_lock`: with RAM 12, refused with RAM still 12.
6. `test_start_turn_respin_ignores_respin_lock`: the wheel still respins at turn start and the checkpoint is set.
7. `test_spin_flip_freeze_unaffected_by_locks`: all three validate ok.
8. `test_refusal_precedence`: locked AND resistance > 0 AND RAM 0 → the reason is LOCKED first (a fixed order, asserted).
9. `test_nudge_lock_on_enemy_wheel_blocks_player_nudging_it`: the Linked Bus Daemon's nudge is also refused (assert the chosen rule).
10. `test_refusal_reason_is_in_reasons_enum_and_has_us_english_text`: cross-check with test_us_english.

**test_lock_effects.gd**
1. `test_lock_effect_targets_target_wheel`: the effect lands on the TARGET_WHEEL's owner.
2. `test_lock_applies_before_player_phase`: an enemy slice resolved at End Turn sets turns=1; the lock is visible next player phase and gone the turn after.
3. `test_preview_shows_lock_equals_result`: the preview reports "locks next turn" and the post-resolve state matches (extends the test_preview patterns).
4. `test_lock_on_sandboxed_attack_not_applied`: an attack negated by SANDBOX applies no lock if the lock rides the hit (assert the chosen rule).
5. `test_lock_conditional_on_needle_start_tick`: the Halcyon rule "when its needle starts on Curfew" is true for tick 10 and false for tick 11.
6. `test_lock_idempotent_same_turn_same_source`: no double count.
7. `test_n6_listener_lock_optional`: skipped by a `skip_if_missing` guard when N6 is absent; with N6, a lock fires on ON_PERFECT.

**test_lock_content_validation.gd**
1. `test_validate_rejects_negative_turns`: "lock_turns must be >= 1".
2. `test_validate_rejects_lock_without_source_id`.
3. `test_validate_rejects_lock_turns_over_max_3`.
4. `test_validate_rejects_lock_on_normal_enemy_without_flag`: only if the draft rule exists; otherwise drop.
5. `test_validate_accepts_valid_lock`.

**test_lock_replay_save.gd**
1. `test_seeded_replay_with_locks_same_hash`: record 5 turns with seed 4242 and a Halcyon-like boss, replay, compare hashes.
2. `test_no_global_randi_in_lock_paths`: grep-style test over the lock functions, and the RngService stream counters are unchanged by locking.
3. `test_rewind_restores_lock_state_within_turn`: an enemy lock set at a staged action undoes cleanly.
4. `test_rewind_never_crosses_checkpoint_with_lock`: the lock persists across an undo that is blocked at the checkpoint.
5. `test_undo_clean_after_refused_nudge`: the undo stack depth is unchanged.
6. `test_save_round_trip_lock_equal`: mid-fight save with turns_left=2, load, and the dictionaries are equal.
7. `test_load_pre_n7_save_defaults_no_lock`: a fixture without the fields loads with empty locks.
8. `test_tie_break_multiple_locks_sorted_by_source_id`.

**test_lock_sweep.gd (full)**
1. `test_200_seeds_never_deadlock`: the player always has at least one legal action (End Turn).
2. `test_sweep_hash_stable_across_two_runs`.

**test_lock_overlay_flow.gd**
1. `test_overlay_visible_when_locked_hidden_after_expiry`.
2. `test_refused_click_shows_reason_toast`.
3. `test_keyboard_nudge_key_refused_shows_reason` (mouse/keyboard only).

## 5. Existing tests likely to break
- `test_respin_action.gd` and `test_rewind.gd`: the validate_action signature or reason enum may change; adapt the expected reason strings.
- `test_resistance.gd`: refusal ordering assertions (resistance vs lock).
- `test_replay.gd` and `test_save_service.gd` (integration): the state hash and save dict gain the lock fields; regenerate golden hashes.
- `test_us_english.gd`: scans the new reason strings.
- `test_codex_terms.gd`: new glossary entries for the locks.
- Grep `validate_action(` in `tests/` for exact-dict comparisons.

## 6. Order
Write `test_lock_validation.gd` case 1 (`nudge_refused_when_locked_reason_nudge_locked`) and case 3 (a card nudge still works) first. Together they pin the scope ruling (nudge actions blocked, cards allowed) before any code exists. Next come test_wheel_locks 3 and 5, so the tick-down and stacking semantics are fixed. Replay, save and sweep come last.
