# test plan: N6 Enemy listeners

## 1. What is a rule here
**Rule-bearing (unit tests):**
- `rc.gd` additions: the `Trigger` entries ON_RAM_SPENT and ON_HIT_DEALT, appended at the end so existing enum ints stay stable.
- `ListenerData` (or the equivalent field on `enemy_data` / `hub_core_data`) and its `validate()`.
- `combat_resolver._apply_nudge`, `_apply_card` and `_resolve_pointer`, at the points where listeners fire.
- The listener effect queue: ordering, the per-turn and per-combat fire caps, and the no-recursion guard.
- The preview path that computes listener outcomes without committing them.
- Undo and rewind of staged actions that triggered listeners.
- Save round trip of listener counters (fires this turn, fires this combat).

**View glue (flow test only):** a "listener fired" chip or tooltip on the enemy HUD, and the preview breakdown line. These get one integration flow test that checks the chip text matches the preview number. No unit tests.

## 3. Cases

**test_enemy_listeners.gd**
1. `test_on_nudge_listener_fires_once_per_nudge`: a listener "+2 BLOCK per paid nudge"; do 3 nudges, the first free. Assert it fired 3 times, block = 6, and each nudge's RAM cost is unchanged.
2. `test_on_card_played_fires_per_card_and_not_on_rejected_play`: play 2 cards, then try a card with insufficient RAM. Assert fires = 2.
3. `test_on_perfect_fires_only_on_perfect_tier`: land Perfect, Good and WEAK on separate resolves. Assert fires = 1, on the Perfect only.
4. `test_on_perfect_counts_each_pointer_separately`: a 2-needle player wheel, both reading Perfect. Assert 2 fires.
5. `test_on_ram_spent_fires_with_amount_in_context`: spend 3 RAM (nudge plus a 2-cost card). Assert the fire amounts are [1, 2].
6. `test_on_ram_spent_ignores_zero_cost_actions`: the free nudge. Assert 0 fires.
7. `test_on_hit_dealt_fires_after_damage_with_final_amount`: a 7-damage hit with 3 block. Assert the context carries the final value, and the listener sees the block already consumed.
8. `test_listener_damage_uses_tier_factor`: flat 4 at T3 (×1.69). Assert 6 (ceil 6.76 or the project's rounding rule; pin it to the one in `_scaled`).
9. `test_listener_percent_amount_not_rescaled`: PERCENT 10 % of a 300 max HP enemy at T4. Assert 30, with no tier multiplication.
10. `test_listener_fire_cap_per_turn`: cap 2, 4 triggers. Assert 2 fires.
11. `test_listener_cap_resets_at_turn_start`: assert the counter is 0 after `start_turn`.
12. `test_listener_cap_per_combat`: cap 3 per combat across 2 turns. Assert 3.
13. `test_listener_does_not_trigger_listeners`: a listener's own damage must not fire ON_HIT_DEALT (recursion guard). Assert fires = 1.
14. `test_multiple_listeners_order_by_content_id_then_slot`: two listeners with ids "a" and "b" on the same trigger. Assert the effects apply in id order regardless of authoring order.
15. `test_listener_on_dead_or_phase_parked_enemy`: the listener still fires while HP is parked at the floor (R3); it does not fire once the enemy is dead.
16. `test_listener_survives_phase_change_unless_replaced`: a P2 `wheel_override` swaps listeners. Assert the P1 listener is gone and the P2 one is active.
17. `test_listener_disabled_by_hub_breach`: a hub-owned listener is inactive for the breached turn and active the next turn.
18. `test_sandboxed_attack_still_fires_on_hit_dealt_zero`: define and pin the behavior. A SANDBOXed hit does not fire ON_HIT_DEALT.

**test_listener_preview.gd**
1. `test_preview_equals_result_nudge_listener`: stage a nudge, read the preview of block and damage, commit, compare the combatant state field by field.
2. `test_preview_equals_result_perfect_clawback`: preview a Perfect with a "4 damage to player on Perfect" listener. Assert the player's HP after resolve = preview HP.
3. `test_preview_equals_result_card_listener_with_capped_fires`: 3 cards against cap 2. Assert the preview after card 3 shows no extra effect.
4. `test_preview_does_not_mutate_state`: hash before and after a preview call is identical, and the fire counters are unchanged.
5. `test_preview_lists_listener_breakdown_entries`: assert one entry per fire with listener id and amount.
6. `test_preview_includes_listener_damage_in_lethal_check`: a listener hit that would kill the player is previewed as lethal.

**test_listener_undo.gd**
1. `test_undo_nudge_reverts_listener_effects`: nudge, undo. State hash equals the pre-nudge hash.
2. `test_undo_card_reverts_listener_and_counter`: the fire counter is decremented, so a re-play fires again.
3. `test_undo_stack_of_five_actions_returns_to_checkpoint_hash`.
4. `test_rewind_cannot_cross_checkpoint_with_listener_fires`: after a Respin checkpoint, undo stops at the checkpoint and the earlier fires stay.
5. `test_listener_fires_during_staging_do_not_leak_into_resolve`: stage, undo, End Turn. Assert no stale queued effects.
6. `test_redo_after_undo_matches_original_result`.

**test_listener_determinism.gd**
1. `test_seeded_replay_same_hash`: record a 3-turn input log against a listener enemy, replay, compare the final hash.
2. `test_listeners_use_no_rng`: snapshot all RngService stream positions before and after a fight where listeners fired. Assert none moved because of them.
3. `test_listener_source_has_no_global_randi`: a grep-style assertion over the listener script files, banning `randi(`, `randf(` and `randomize(`.
4. `test_different_seed_same_inputs_same_listener_fires` (fires are input-driven, not random), compared on the fire log.

**test_listener_content.gd**
1. `test_validate_rejects_unknown_trigger`: reason names the trigger.
2. `test_validate_rejects_player_only_triggers` (e.g. ON_NETRUN_COMPLETE on an enemy listener).
3. `test_validate_rejects_random_slice_pick_in_listener`: SlicePick.RANDOM_NON_NULL needs a pre-committed pick, because there is no random input inside an action.
4. `test_validate_rejects_negative_or_zero_cap`.
5. `test_validate_rejects_percent_over_100`.
6. `test_validate_rejects_listener_that_triggers_listener_trigger`.
7. `test_all_shipped_enemies_with_listeners_validate`: run over content.

**test_listener_save.gd**
1. `test_round_trip_preserves_fire_counters`.
2. `test_mid_turn_resume_then_nudge_respects_cap`.
3. `test_old_save_without_listener_fields_loads_defaults` (the data-only fallback: no listeners means the old behavior).

**test_listener_sweep.gd (full)**
1. `test_every_listener_enemy_fight_completes_and_never_negative_hp`: 20 seeds, bot play.
2. `test_listener_fires_logged_in_sim_metrics` (the N19 hook).

**integration/test_listener_flow.gd**
1. `test_chip_shows_on_nudge_and_matches_preview`.
2. `test_undo_clears_chip`.

## 4. Fixtures and helpers
- `tests/fixtures/listener_enemy_factory.gd`: builds a one-phase enemy from a dict (trigger, effect, cap, amount mode).
- Seeds: 1000, 1001, 1002; the sweep uses 1000:1019.
- `tests/helpers/state_hash.gd`, if none exists: a stable hash of combatants, wheels, RAM, counters and the RNG stream positions.
- An input-log recorder, reused from `test_replay.gd`.
- Waits follow the `bounded_wait.gd` conventions (bounded frames, no bare awaits).

## 5. Existing tests likely to break
- `test_preview.gd`, `test_plan1_a2_preview.gd`, `test_w1_tag_preview.gd`: the preview structure gains listener entries. Grep for exact dictionary key comparisons.
- `test_rewind.gd`, `test_replay.gd`: state-hash field lists must include the new counters.
- `test_resolution_order.gd`: ON_HIT_DEALT adds a step. Assert that the order is unchanged for enemies without listeners.
- `test_suite_integrity.gd`, `test_boss.gd`: grep for Trigger enum int pins.
- `test_save_service.gd`: save field additions.

## 6. Order
1. Write `test_no_listeners_means_unchanged_hash` first, in `test_listener_determinism.gd`. It fixes the data-only baseline: any existing enemy fight replays to the same final hash before and after N6. It passes with no code and guards everything after.
2. Then `test_preview_equals_result_nudge_listener` and `test_undo_nudge_reverts_listener_effects`. These two define the hardest contract.
3. Then triggers, caps, validation, save.
