# test plan: N11 Pointers on any tick

## 1. What is a rule here
**Rule-bearing (unit tests):**
- `combat_resolver` pointer placement: `EXTRA_POINTER_OFFSETS` replaced by data-driven pointer ticks. The tick under each pointer is `(rotation + pointer_tick) mod 30`. Multiples of 5 are no longer assumed.
- Pointer-set changes by boss phase (MULTIPLY / MIGRATE / ORBIT) now accept any tick 0–29.
- The pointer rule (GDD 2.7): one attack lands once per pointer, each with its own slice, offset and tier.
- Preview and resolution share one path.
- `EnemyData` / `BossPhaseData.validate` on pointer offsets.
- Save round trip of pointer ticks.
- `wheel_math` is untouched (N12 owns slice geometry). N11 only feeds it arbitrary ticks.

**View glue (flow test only):** `ui/wheel` needle drawing, close-needle readability (label de-overlap), HUD chips. Per rule 6 there are no unit tests on pixels. One scene flow test asserts that two pointers 1 tick apart both render, with distinct chip positions.

## 3. Cases
**test_pointer_ticks.gd**
1. `test_pointer_at_tick_1_reads_good_on_slice_0`: rotation 0, pointer tick 1. Assert slice 0, offset +1, GOOD.
2. `test_pointer_at_tick_2_reads_weak`: pointer tick 2. Assert WEAK (0.5×).
3. `test_pointer_at_tick_3_reads_next_slice_weak`: tick 3 gives slice 1, offset −2, WEAK.
4. `test_pointer_tick_29_wraps_to_slice_0`: tick 29 gives slice 0, offset −1, GOOD.
5. `test_every_tick_0_to_29_resolves_a_slice_and_tier`: loop all 30. Assert slice in 0..5, no miss tier, and exactly 6 PERFECT ticks.
6. `test_two_pointers_0_and_14_resolve_independently`: Shim wheel; assert slices (0, 3), tiers (PERFECT, WEAK at offset −1 → GOOD; pin exact values).
7. `test_two_pointers_1_tick_apart_hit_two_slices_when_on_boundary`: ticks 2 and 3. Assert damage lands twice with WEAK each (0.5× each).
8. `test_two_pointers_same_tick_both_resolve`: ticks 7 and 7. Assert two hits, no dedup.
9. `test_rotation_shifts_uneven_pointers_together`: rotation +4 on pointers (0, 11). Assert ticks (4, 15).
10. `test_pointer_tick_out_of_range_rejected`: tick 30 or −1 returns the validate reason `pointer_tick_out_of_range`.

**test_pointer_phases.gd**
1. `test_multiply_to_0_14_gives_two_uneven_pointers`: the Genome Core P3 case. Assert pointer ticks [0, 14].
2. `test_multiply_to_0_11_and_0_13_valid`: REBEL_CELL / Halcyon cases.
3. `test_legacy_evenly_spaced_offsets_still_produce_15_and_10_spacing`: data-only fallback. Default MULTIPLY with no ticks authored yields 15 / 10 spacing, identical to the old `EXTRA_POINTER_OFFSETS` results.
4. `test_migrate_to_odd_tick_applies_after_telegraph_turn`: telegraph at turn N, applied at N+1, tick 13.
5. `test_orbit_by_3_wraps_mod_30`: start 28, orbit 3, expect 1. Trail preview ticks equal the actual ticks for 3 turns.
6. `test_duplicate_pointer_ticks_validate_ok_or_named_reject`: pin the ruling (see Q1).
7. `test_pointer_count_cap_rejected`: more than 4 pointers returns `too_many_pointers`.
8. `test_validate_content_all_enemies_pointer_ticks_in_range`: iterate the registry in id order, then fail on the first bad one with its id.

**test_pointer_preview_replay.gd**
1. `test_preview_equals_result_uneven_pointers`: seed 1101, pointers (0, 14); compare preview chips to post-resolve HP / block / statuses.
2. `test_preview_equals_result_after_nudge_moves_one_pointer_to_boundary`: nudge 1 tick, re-preview, resolve, and assert equal.
3. `test_replay_same_seed_same_inputs_same_state_hash`: record a 5-turn fight with uneven pointers; replay; hashes equal.
4. `test_pointer_resolution_order_is_pointer_index_ascending`: tie-break by pointer index, then the existing pass order, so two pointers on one slice give a stable order of effects.
5. `test_rewind_does_not_cross_respin_checkpoint`: with uneven pointers, undo past the start-of-turn respin is refused.
6. `test_undo_restores_pointer_ticks_after_phase_change_stage`: stage a phase cross in preview, undo, and assert the pointer array is unchanged.
7. `test_no_global_randi_in_pointer_placement`: grep-style assertion over `combat_resolver.gd` that pointer code uses no `randi(` or `randf(`; plus a stream-counter check showing placement draws 0 values.
8. `test_parked_damage_with_two_pointers_one_threshold`: the first pointer's hit parks, so the second is lost (R3 interaction). Assert HP == floor.

**test_pointer_save.gd**
1. `test_save_round_trip_preserves_pointer_ticks`: state hash equal after load.
2. `test_legacy_save_with_offsets_loads_to_equivalent_ticks`: a fixture saved with the old offset field.
3. `test_save_version_unchanged_if_field_additive`: assert `SAVE_VERSION` is not bumped (otherwise add a migration case).

**integration/test_pointer_close_needles.gd**
1. `test_adjacent_needles_both_drawn_with_separate_chips`: pointers 1 tick apart; both needle nodes exist and their chip rects don't overlap.
2. `test_tooltip_lists_each_pointer_slice_and_tier`: hover text contains two entries.

- `unit/test_targeting.gd` (pointer rule), `unit/test_preview.gd`, `unit/test_replay.gd`, `unit/test_rewind.gd`: may hard-code pointer arrays; grep `EXTRA_POINTER_OFFSETS` and `pointer_offsets`.
- `unit/test_boss_save_writer.gd`, `integration/test_save_service.gd`: a pointer field rename affects them.
- `unit/test_wheel_math.gd`: should pass unchanged. Treat any failure as an N12 leak.
- `unit/test_parity_wheel.gd`, `unit/test_w2_a5a6_ring.gd`: needle layout assertions.
- `unit/test_balance_sim.gd`: golden numbers if sim fights use multi-pointer enemies.

## 6. Order
