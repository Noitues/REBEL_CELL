# test plan: N9 Status rules + corruption as a RAM cost

N9 assumes N8 (×N stacks, save v3) is done. Tests below use the N8 stack API `{status: stacks}` and say so where it matters.

## 1. What is a rule here

**Rule-bearing (unit tests):**
- `scripts/data/rc.gd`: new `Status` entries OUTPUT_DOWN and TIER_DOWN, appended so existing enum ints stay stable for saves.
- `combat_resolver`:
  - cost paths (card cost, paid nudge, free-nudge accounting, undo refunds);
  - `_corrupted_trigger` (now damage-free);
  - tier-downgrade and output-multiplier application in `_resolve_pointer`;
  - OVERCLOCKED burnout into CORRUPTED.
- `effect_interpreter.apply_status`, `cleanse`, and the status stack math (OUTPUT_DOWN ×N, TIER_DOWN ×N, ENCRYPTED absorb).
- `parasite_handler`: the PARASITE status becomes OUTPUT_DOWN ×2 (the Botnet Perfect Trojan still plants it).
- `campaign_config_data`: `corrupted_ram_cost_multiplier` = 2. The retired `corrupted_self_damage`, `corrupted_damage_per_major` and `corrupted_ram_drain` must be gone.
- The RAM forecast calculation: a pure function that gives the cost of an action from the state. The preview must call the same function the resolver uses.
- Content validation that rejects the retired fields or an invalid multiplier.

**View glue (flow test only):** `ram_bar.gd` forecast chip rendering, ×N badges, Codex and tutorial text. Check only that the text exists, is US English, and that the chip shows the number the rule function returns.

## 3. Cases

### test_status_output_tier.gd
1. `test_output_down_one_stack_cuts_25_percent`: slice of 8 damage, 1 stack → 6.
2. `test_output_down_two_stacks_cuts_50_percent`: 8 → 4. Assert additive stacks, not compounding (0.75² would give 4.5).
3. `test_output_down_four_stacks_floors_at_zero`: 4 stacks = 100 % off → 0, never negative; 5 stacks also 0.
4. `test_output_down_rounding_is_deterministic`: 5 damage × 0.75 = 3.75; assert one fixed rounding rule (round half up → 4) at 1, 2 and 3 stacks.
5. `test_parasite_status_is_output_down_two`: Botnet Perfect Trojan on an enemy slice → slice reads OUTPUT_DOWN ×2, same output as the old halving (10 → 5).
6. `test_parasite_status_legacy_equals_new`: parity check of the old and new output on 20 slice values.
7. `test_tier_down_perfect_becomes_good`: landing at offset 0 with 1 stack → tier GOOD; output stays 1.0×, the Perfect hook does not fire.
8. `test_tier_down_good_becomes_weak`: 1 stack at offset ±1 → WEAK (0.5×).
9. `test_tier_down_weak_stays_weak`: floor, no tier below WEAK.
10. `test_tier_down_two_stacks_perfect_to_weak`.
11. `test_tier_down_hides_perfect_hooks`: Perfect hook, Kernel Sync and Clean Signal don't trigger on a downgraded landing.
12. `test_status_applies_on_weak_landing`: per the open Q11 default (yes).
13. `test_encrypted_absorbs_one_new_status_instance`: ENCRYPTED then OUTPUT_DOWN → ENCRYPTED consumed, no stacks added.
14. `test_cleanse_removes_all_stacks_of_one_status`.
15. `test_overclocked_burnout_becomes_corrupted`: still true after the self-damage retirement.
16. `test_output_down_and_overclocked_multiply_order`: 1.5× then −25 %; fix the order and the exact value (8 → 12 → 9).

### test_corruption_ram_cost.gd
1. `test_card_on_corrupted_slice_costs_double`: a 1-RAM card where the acting pointer reads CORRUPTED → 2 RAM spent.
2. `test_card_cost_zero_stays_zero`: 0 × 2 = 0.
3. `test_card_on_clean_slice_costs_base`.
4. `test_paid_nudge_on_corrupted_costs_2`: second nudge of the turn, corrupted slice → 2 RAM.
5. `test_free_nudge_on_corrupted_costs_zero`: the free nudge remains free (Q3 default; flag it as a Q).
6. `test_cost_judged_where_pointer_reads`: the cost depends on the slice at the acting pointer *before* the action, not after it. Nudge off a corrupted slice → still ×2.
7. `test_multiplier_reads_config_not_literal`: set the multiplier to 3 → 3 RAM; set it to 1 → base cost.
8. `test_corrupted_trigger_deals_no_self_damage`: corrupted slice resolves; player HP unchanged at any Heat MAJOR count 0–3.
9. `test_corrupted_trigger_no_ram_drain`: RAM unchanged on resolve (retired `corrupted_ram_drain`).
10. `test_corrupted_enemy_slice_no_damage`: a corrupted enemy slice neither damages nor drains the enemy.
11. `test_insufficient_ram_refused_with_reason`: 1 RAM left, 1-RAM card on corrupted → refused, reason names the doubled cost; the state is unchanged.
12. `test_ram_cap_12_unaffected`.
13. `test_forecast_function_matches_spend`: for 30 (cost, corrupted, nudge-index) combinations, the forecast equals the actual RAM delta.
14. `test_forecast_total_for_staged_sequence`: card, nudge, card; the forecast total equals the final RAM delta.

### test_n9_preview_replay.gd
1. `test_preview_equals_result_output_down`: preview damage at the pointer equals the damage after End Turn, for stacks 0–3.
2. `test_preview_equals_result_tier_down`: the preview tier equals the resolved tier.
3. `test_undo_clean_status_applied_by_card`: stage a card that applies the status, undo; state hash equals the pre-card hash.
4. `test_undo_refunds_doubled_ram`: spend 2 RAM on a corrupted slice, undo → RAM restored exactly.
5. `test_undo_after_nudge_off_corrupted_restores_cost_basis`.
6. `test_rewind_never_crosses_checkpoint`: respin sets a checkpoint, the status-related cost is not refunded across it. Assert the undo is refused.
7. `test_seeded_replay_same_hash`: record 3 turns of inputs, seed 4242, with corrupted and OUTPUT_DOWN slices in play; replay twice → equal final state hash.
8. `test_no_global_randi`: the status and cost paths consume no RNG. The RngService stream positions before and after a pure-cost action are identical.
9. `test_random_non_null_pick_uses_named_stream`: the DOSE-style status application advances only its combat stream.
10. `test_tie_break_multiple_pointers`: two pointers read statuses on different slices, resolution order is stable by pointer index and slice id.

### test_n9_save_content.gd
1. `test_save_round_trip_new_statuses`: save and load mid-fight with OUTPUT_DOWN ×3 and TIER_DOWN ×1; hash equal.
2. `test_old_parasite_save_migrates_to_output_down_two`: a v2 fixture with PARASITE loads as OUTPUT_DOWN ×2 (the version stays N8's v3; if migration is N8's, assert it here as a cross-check).

6. `test_content_validate_unknown_status_rejected`.
7. `test_all_content_passes_validate`: tools/validate_content equivalent.

## 6. Order
Write `test_corruption_ram_cost.gd` cases 8, 9 and 1 first, plus `test_parasite_status_is_output_down_two`. Before any code, they prove the contract is falsifiable: the retired damage is gone, the 2× cost, and the PARASITE alias. Then `test_forecast_function_matches_spend`, which pins the single shared cost function the preview and resolver must use. The save migration and sweep come last.
