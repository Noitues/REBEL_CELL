# test plan: N13 Fixed satellites + replacement

## 1. What is a rule here
Rule-bearing (unit tests, per CLAUDE.md rule 6):
- `combat_resolver.validate_action`: refusal of any action that would move a satellite's wheel (nudge, spin, flip, respin, freeze, snap), with named reasons. A refusal must leave state untouched.
- `combat_resolver._spawn_satellite`: the `on_occupied = REPLACE` branch (new satellite replaces the one on the slice, with a defined fate for the old one) and the default branch.
- `undock_handler`: scope to `can_move_satellites`.
- `can_move_satellites` resolution: class, Firmware and Daemon sources, OR-combined, read through one query function.
- `satellite_spawn_data.validate`: rejects bad `on_occupied` values.
- Host-wheel spin, flip and respin carry docked satellites unchanged (GDD 2.7 holds).
- Preview (`validate_action` result reasons, spawn preview) and rewind/undo staging.

View glue (flow test only): the UI refusal toast, disabled satellite nudge arrows, a "fixed" badge. Covered by one integration flow.

## 3. Cases
**test_satellite_fixed.gd**
1. test_nudge_on_satellite_wheel_refused_without_flag_names_reason: dock a satellite and call validate_action with a satellite NUDGE. Expect invalid, reason `SATELLITE_FIXED`.
2. test_spin_flip_respin_freeze_snap_on_satellite_refused: loop over each action type. All refused with the same reason.
3. test_refusal_leaves_state_hash_unchanged: hash before and after the refused apply attempt. Equal.
4. test_class_flag_allows_satellite_nudge: operative class with `can_move_satellites`. Valid, and the satellite rotation changes by 1.
5. test_firmware_flag_allows_move: same, via Firmware.
6. test_daemon_flag_allows_move: same, via Daemon.
7. test_flag_sources_or_combine_no_double_effect: class and Firmware both set. Valid, and the move is still exactly 1 tick.
8. test_flag_granted_by_firmware_only_while_equipped: unequip it, and the move is refused again.
9. test_host_spin_carries_satellite_with_fixed_slice: spin the host by 7. The satellite stays on the same slice index and its mini-wheel rotation is unchanged.
10. test_host_flip_keeps_satellite_docked_to_slice: flip. The slice moves, the satellite goes with it, and its internal rotation is unchanged.
11. test_host_respin_does_not_touch_satellite_wheel: respin and check the satellite's rotation. The RNG stream is drawn once per host wheel, never per satellite.
12. test_satellite_own_start_of_turn_respin_unaffected: fixed means no player movement. Confirm the start-of-turn respin rule still applies (assert the current GDD behavior, flagged in the file header).
13. test_no_satellites_actions_unchanged: edge case with 0 satellites. No new refusals anywhere.
14. test_enemy_resistance_not_consulted_for_refused_move: resistance stays at its value after a refusal.

**test_satellite_replace.gd**
1. test_spawn_on_occupied_replace_swaps_satellite: dock A on slice 2, spawn B with REPLACE. Slice 2 holds B and A is gone.
2. test_spawn_on_occupied_default_keeps_old_behavior: no REPLACE, so the legacy path (next free slice or refuse, whichever exists today) is unchanged.
3. test_replace_new_satellite_starts_full_hp_and_fresh_intent: B has its template HP and the intent for the current tick.
4. test_replace_on_empty_slice_acts_as_plain_spawn: edge case, nothing replaced.
5. test_replaced_satellite_removed_from_resolution_pass: End Turn resolves B only, A does not fire.
6. test_replaced_satellite_fires_no_on_destroy_hooks_by_default: Daemon hooks keyed to destruction don't fire. Pins Q: below.
7. test_replace_all_six_slices_full_ring: the ring is full and a 7th spawn replaces the slice chosen by the rule. Spawn order is deterministic.
8. test_replace_target_tie_break_content_id_then_slot: two spawns in one resolve with the same target. The later one by (content id, slot index) wins, and the result is identical across 20 runs.
9. test_bodyguard_redirect_hits_replacement: a pointer attack on the slice hits B, not A.
10. test_spawn_preview_equals_result: the preview of "replaces X" matches the post-resolve satellites exactly.
11. test_replace_during_resolve_does_not_alter_current_pass_order: A already resolved this pass, B waits until the next turn.
12. test_unknown_on_occupied_value_rejected: covered in content, cross-referenced here.

**test_satellite_undock_scope.gd**
1. test_undock_refused_without_flag_reason_named
2. test_undock_with_flag_removes_only_chosen_satellite
3. test_undock_on_empty_slice_refused
4. test_undock_card_playable_check_matches_validate_action: the card's playable state equals the validator's.
5. test_undock_scoped_to_player_satellites_not_enemy_hosts: Botnet drones are not affected. Drones are not satellites, and their rule is unchanged.

**test_satellite_content.gd**
1. test_satellite_spawn_data_rejects_bad_on_occupied: reason string contains `on_occupied`.
2. test_default_on_occupied_is_documented_value
3. test_all_spawn_content_validates: run validate on every `satellite_spawn_data` resource.
4. test_can_move_flag_defaults_false_on_every_class_except_designated: only the ruled class has it.
5. test_validate_content_script_passes: wraps tools/validate_content.gd.
6. test_codex_text_for_fixed_satellites_us_english: the string exists and passes the US-English lint.

**test_satellite_determinism.gd**
1. test_seeded_replay_with_replacements_same_hash: seed 1313, 6 turns of scripted spawns and refused moves. Two runs give equal hashes.
2. test_refused_actions_in_replay_log_do_not_change_hash: a log with extra refused inputs gives the same hash as one without.
3. test_no_global_randi_in_satellite_paths: seeds are fixed; compare against `RngService` stream draw counts, which must equal the expected number (no new draws).
4. test_rewind_after_replace_restores_old_satellite: replacement is staged, undo restores A with its HP and rotation.
5. test_rewind_cannot_cross_checkpoint_with_replace: replace, then a respin sets a checkpoint, and undo stops there.
6. test_save_round_trip_after_replace_equal_state_hash
7. test_save_with_pre_n13_satellites_loads: an old save has no `on_occupied` field and loads with defaults. No version bump, so no migration. The test asserts the save version is unchanged.

**integration/test_satellite_flow.gd**
1. test_ui_refusal_shows_reason_and_no_state_change: click a satellite nudge arrow, and the toast shows the reason.
2. test_replace_spawn_shows_replacement_in_view: use bounded_wait.

- Tests that nudge or spin a satellite directly, or use the Undock card: grep `test_targeting.gd`, `test_resolution_order.gd`, `test_drones.gd`, `test_cards.gd`, `test_wheel_math.gd` and `test_boss.gd` for `SATELLITE`, `WheelTarget.SATELLITE`, `undock`, `_spawn_satellite`. - Tests that assert the spawn-on-occupied fallback (next free slice): `test_targeting.gd` and `test_enemies_m2.gd`. Keep them for the default branch.
- `test_firmware_daemon_coverage.gd` and `test_classes.gd`: new flag fields need entries.
- `test_balance_sim.gd`: the bot may use satellite nudges, so check its moves and the baseline.

## 6. Order
Write test_satellite_fixed.gd case 1 and case 3 first. A refused satellite nudge returns invalid with `SATELLITE_FIXED` and leaves the state hash unchanged. Before any code, these pin the refusal contract and the state-purity guarantee that every dependent draft relies on. Then case 9, which pins the carry rule so the change cannot break host spin or flip, followed by the replace tests.

Q: When a satellite is replaced, does it count as destroyed (Daemons, rewards)? Case 6 assumes no, pending the ruling.
Q: Does the bot or sim use satellite nudges today? That decides whether the baselines move.
Q: Does the satellite's own start-of-turn respin still occur? Case 12 pins current behavior.
