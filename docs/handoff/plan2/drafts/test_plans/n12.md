# test plan: N12 Variable slice sizes + sub-tick map

## 1. What is a rule here

**Rule-bearing (unit tests):**
- `scripts/core/wheel_math.gd`: cumulative-boundary geometry (`slice_at`, `offset`, `tier`, `mirror`, `snap`, Mirror/Shunt neighbor lookup). This is the core of N12.
- `wheel_state`: slice storage, rotation, flip, nudge, spin, `snap_to_center`, and the status remap that depends on slice centre ticks (R6, N3).
- `wheel_slot_data`, `wheel_data`, `firmware_data` `validate()`: size sum 30, `size_ticks` range, `tick_quality` length, slice-count cap.
- Firmware tick step (raises each sub-tick one tier).
- The shop overwrite rule (replacing a slot keeps sum = 30).
- `combat_resolver._resolve_pointer` as the consumer of geometry (preview == result).
- Save migration for slots without `size_ticks`.

**View glue (one flow test, no unit tests):** `wheel_wedge.gd` drawing, `loadout_view.gd` sub-tick map rendering, wheel-face labels. Covered by a single integration scene test that asserts the wedge angles derive from the same WheelMath boundaries, plus the map strings.

## 3. Cases

**test_wheel_sizes.gd**
1. `test_default_map_size2_is_GG`: build [2,...]; assert map strings for sizes 2-7 equal the R11 table exactly.
2. `test_size4_has_no_perfect`: every tick of a 4-slice resolves WEAK/GOOD only.
3. `test_size7_centre_is_perfect`: d=0 PERFECT, d≤1 GOOD, d=2,3 WEAK.
4. `test_even_size_centre_is_left_of_pair`: pin the centre rule for even sizes (see Q1); size 4 ticks 0-3 read W G G W.
5. `test_slice_at_cumulative_boundaries`: sizes [6,4,4,6,4,6]; every tick 0-29 maps to the expected index (table in the fixture).
6. `test_offset_signed_from_centre`: offsets sum-check per slice (size 5: -2..+2).
7. `test_every_tick_maps_to_exactly_one_slice`: for 200 seeded layouts, the slice counts sum to 30.
8. `test_uniform_5x6_matches_legacy_tables`: new code vs the old golden table, 30 of 30 ticks.

**test_wheel_layout_validation.gd**
1. `test_sizes_not_summing_30_rejected` (29 and 31; reason "size_sum").
2. `test_size_1_rejected`, `test_size_8_rejected` (reason "size_range").
3. `test_tick_quality_wrong_length_rejected` (size 4 with 3 entries).
4. `test_slice_cap_lifted_to_N`: 10 slices of 3 valid; 16 slices of 2 hits the new cap (reason "slice_cap", confirm the cap value).
5. `test_missing_size_ticks_defaults_to_5`: legacy 6-slot data valid.
6. `test_validate_content_all_enemies_pass`: all `content/enemies` still validate.

**test_wheel_geometry_ops.gd**
1. `test_mirror_maps_ticks_involution`: mirror twice = identity for 100 layouts and pointers (including odd ticks, R10).
2. `test_flip_reverses_order_keeps_sizes`: sizes [6,4,3,...] reversed order after flip.
3. `test_snap_to_center_moves_to_nearest_centre`: tie goes to the lower slice index.
4. `test_snap_on_size4_lands_on_good_not_perfect`: no centre tick; the rule is documented.
5. `test_mirror_firmware_neighbor_uneven`: landing clockwise of centre in a size-3 slice copies the cw neighbor.
6. `test_shunt_nothing_on_perfect_uneven`; size 4 never Perfect, so Shunt always fires.
7. `test_nudge_wraps_at_30`; `test_spin_by_30_identity`.
8. `test_pointer_on_odd_tick_resolves` (R10: tick 14, 0 together).

**test_tick_quality_firmware.gd**
1. `test_calibrated_raises_each_subtick_one_tier`: size 4 W G G W becomes G P P G.
2. `test_calibrated_caps_at_perfect`: size 5 stays W→G, G→P, P→P.
3. `test_override_map_beats_default`.
4. `test_calibrated_on_override_map`.
5. `test_firmware_removed_restores_default_map`.

**test_variable_size_combat.gd**
1. `test_preview_equals_result_uneven_wheels`: 50 seeds, compare the preview dict and the resolve deltas.
2. `test_two_uneven_needles_distinct_tiers`: needles 0 / 14 on the Genome P3 layout yield different quality.
3. `test_seeded_replay_same_state_hash`: record 10 turns, replay, compare hash.
4. `test_geometry_uses_no_global_rng`: grep guard plus RngService stream counters unchanged by WheelMath calls.
5. `test_status_remap_after_layout_change`: CORRUPTED on slice with centre tick 12 lands on the new slice covering tick 12; two statuses merge on one slice.
6. `test_rewind_does_not_cross_checkpoint_after_resize`.
7. `test_undo_clean_nudge_on_uneven_wheel`: the state hash is identical after stage and undo.
8. `test_perfect_hook_fires_only_on_true_perfect`: size 4 never triggers.

**test_wheel_size_save.gd**
1. `test_round_trip_variable_wheel_equal`.
2. `test_legacy_save_without_size_ticks_loads_as_5` (fixture).
3. `test_shop_overwrite_keeps_sum_30`: replacing a 5 slot with a 4 slot is rejected or compensated per the rule; assert the named reason.

**test_wheel_size_sweep.gd (full)**
1. `test_random_layouts_all_ticks_covered`: 2000 seeded layouts.
2. `test_resolve_total_invariant_under_rotation`: slice-time sums.

**integration/test_loadout_subtick_map.gd**
1. `test_loadout_shows_map_string_per_slice`: "W G G W" for size 4.
2. `test_wedge_angles_match_wheelmath_boundaries`: within 0.001 rad.
