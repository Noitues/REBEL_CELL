# NA-03: `tools/netrun_art/` pure modules (no Blender)

- **Goal:** Port the concept scripts to pure Python modules under `tools/netrun_art/`: layout, zoning, derive.street, hq.slots, rig, lod, occlusion, section, states, dress, seeds, io. Nothing imports `bpy`. They read the NA-02 contract JSON and write derive JSON v1. They are the reference twins for NA-04 (checks) and NA-21 (GDScript parity).
- **Base / tag:** `<BASE_SHA>` / `<TEMP_TAG>` (NA-02 merged)
- **Agent type and lane:** Batch (one draft per module, ported from the pinned concept-script commit) + fix-mechanical (integration, tests, determinism). No Opus: nothing here touches `scripts/core` or RNG streams.
- **Depends on:** NA-02 (data contract and schemas)

Read first: `docs/handoff/netrun_art/NA03_MODULES.md`. The orchestrator pre-writes it. It holds the pinned concept-script commit and file per module, each module's public function signatures, the spec § it implements, and the NA-02 schema paths. If it is missing, report BLOCKED. Do not guess.

## Files
All new, under `tools/netrun_art/`:
- `__init__.py`
- `seeds.py`: FNV-1a 64 over [layout_seed, "art/"+stream, keys]. It reads no gameplay stream.
- `io.py`: canonical JSON (sorted keys, fixed float format, `\n`) and schema validation.

- `tests/` (new), plus fixture seeds under `tests/fixtures/` (≥ 10 seeds, street and HQ).

## Acceptance
1. Importing any module in a process with `bpy` blocked (`sys.modules['bpy']=None`) succeeds.
2. `seeds.py` matches the NA-02 golden vectors (≥ 5 inputs) bit for bit.
3. Derive JSON for each fixture seed is byte-identical across two runs in one process and across a fresh process (§12.3.1). SHA-256 values are in `tests/fixtures/hashes.json`.
4. Seed sensitivity (§12.3.4): changing `layout_seed` by 1 changes the derive hash for 10/10 fixtures. Changing only a gameplay-stream value changes nothing.
5. The §3.3 rule-1 sweep over 200 seeds finds 0 violations (no frontage under 6 floors; hero sign rule holds).
6. `hq.slots` places every node of 3 differing graphs, with 0 overlapping slots and each slot inside its lot.
7. Camera poses, framing and occlusion output for the fixtures are written to `tests/fixtures/expected/*.json`, as the parity inputs for NA-21 (§12.6).
8. All public functions have docstrings, and no module is over 600 lines.
