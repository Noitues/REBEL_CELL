## Acceptance
1. Every check returns a record `{id, status: pass|warn|fail, value, threshold, note}`. The CLI exit code is 1 on any fail, 0 otherwise. Warn never fails.
2. On the art-pass reference inputs, pass/warn/fail matches `rules_check.md` for every row (100 % of rows; a table of the comparison goes in the report).
3. §12.3.1: the data hash computed twice in-process and once in a fresh process is identical for 3 seeds.
4. §12.3.4: a changed layout seed changes the data hash for 3 of 3 seed pairs.
5. §12.6 compares two derive/pose/occlusion JSON files byte for byte. It reports the first differing path. Self-compare passes; a 1-byte mutation fails.
6. Image checks accept any PNG size, with camera parameters read from the plate JSON. The same image checked as a Blender PNG and as a Godot capture differs only through the stated tolerances, none hard-coded.
7. A known-bad fixture fails each image check (dark frame for §12.1, oversized landmark for §12.2). A good fixture passes.
8. Runtime is under 20 s for the full data suite on 3 seeds (the time is reported).
9. Zero Blender, Godot, or network imports in the module (grep-checked in a test).
