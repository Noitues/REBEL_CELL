# N19: Sim metrics (per-phase turns, parked damage, enrage step, intake, listener fires)

- **Goal:** Make the balance sim report the numbers R1-R4 pass criteria need. Per fight and per phase it records turns, parked damage (R3), enrage step reached (R4), player intake, heal turns and listener fires. `balance.py` aggregates them and checks them against the class targets. Collection is observational only.
- **Base / tag:** `<BASE_SHA>` / `<TEMP_TAG>`
- **Agent type and lane:** fix-mechanical, on branch `balance`. No Opus: observational code only, and no core file is touched. If a core file needs a change, stop and report it as a NEEDS line.
- **Depends on:** N3 (phases, parking), N4 (enrage). Listener counts are guarded until N6 lands.

## Acceptance
1. Each fight result carries `phases`: an array of {turns, parked, intake, heal_turns, incomplete}. The phase-change turn counts in the outgoing phase. The sum of `turns` equals the fight turns. A normal gives 1 entry; a zero-turn fight gives `[]`.
2. Parked damage equals the excess over the floor: floor 246, HP 250, hit 20 gives parked 16. It is broken down by path (hit, self, parasite, pierce) and the breakdown sums to the total. The last phase reports parked 0.
3. Intake is unblocked damage to the player, attributed to the phase active at resolve. BLOCK 12 against 5+5+5 gives 3. A SANDBOXed attack gives 0.
4. `enrage_step` is the highest step reached (0 when none), read from N4 state. `listener_fires` is a map from listener id to count, or `null` while N6 is absent.
5. A player death mid-phase records a partial last phase with `incomplete=true`.
6. `balance.py` computes mean and p90 turns, win rate, heal turns per phase (at most 1), and `in_target` (3-4 turns per phase). The `compare` output shows one column per metric. An empty phase list causes no division by zero.
7. Purity: with metrics on and off, the same seed gives an identical state hash and identical fight results. A grep shows no RNG call in the metrics code. A metrics-on run advances no RNG stream.
8. The sweep command `balance.py run fight --enemy <id> --tiers 1,2,3,4 --seeds 1000:1019` emits the new fields. Old result files without them still load, with `null` metrics.
