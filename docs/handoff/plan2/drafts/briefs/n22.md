# N22: EASY / HARD normal-fight pools (designer ruling 2026-10-18, Q12)

- **Goal:** each **normal** enemy is classified EASY or HARD (elites, mini-bosses, bosses are not). In a run, the
  **first 2 normal fights draw from EASY**, every later normal fight from HARD. Fallback when a pool is empty: the other
  pool (deterministic).
- **Base / tag:** `<BASE_SHA>` / `<TEMP_TAG>`.
- **Agent type and lane:** fix-rules. OPUS-BECAUSE: `netrun_session.gd` encounter pick (shared file, REPLAN C.2: one
  slice per merge wave) and the combat RNG stream draw count.
- **Depends on:** N2 merged (same file). Not in the same merge wave as NA-02.

## Files
- `scripts/data/enemy_data.gd`: `normal_pool` (enum in `rc.gd`, append-only: EASY, HARD; default HARD); `validate`
  rejects a pool on a non-normal. Schema change: DECISIONS line + `tools/schema_smoke_checks.gd` check.
- `scripts/core/netrun_session.gd`: `_build_pools` splits `_pools["enemies"]` into easy / hard (sorted by content id);
  the pick at ~309-314 uses the run's count of normal fights already started (a RunState counter, saved). One
  `randi_range` per pick, exactly as today.
- `content/enemies/*.tres`: classify every normal. Proposed rule (designer open to it; write it in
  `docs/handoff/N22_POOLS.md` with one row per normal and its reason): EASY = no listeners or locks, at most one status
  source, resistance 1 (N21), and a reference-deck sim win rate ≥ 90 % at T1 with ≤ 25 % HP lost if sim data exists
  (`tools/balance/`; else judge by the first three). Every corp needs ≥ 2 EASY normals; report any that cannot.
- Special runs (`start_special`) with a forced enemy are unchanged.

## Acceptance
1. Fights 1 and 2 of a run are EASY normals; fight 3+ HARD; elites / Racks / mini-bosses unaffected.
2. The counter survives save / load mid-run; an old save without it loads as 0 normal fights started... unless it is
   already past layer 2: then treat as ≥ 2 (state the rule you implement).
3. Same seed → same encounter sequence; the combat stream advances exactly as before per pick (one draw).
4. Empty EASY pool → HARD (and the reverse), no crash, no extra draw.
5. Every corp's content validates; the classification table matches the `.tres`.
