# Audit of the netrun art documents, scope A: contradictions and cross-references

Documents audited: PIPELINE_SPEC, DIRECTION_REVIEW (DR), `route_map_graph/decisions/DECISIONS.md`, the main-repo replan rulings (D1-D10) and HANDOFF_PACKAGE/README.

Worst problems:
1. The spec still describes superseded designs: the Meridian fortress, the Solace 12-porthole 209 deg helix, the five-territory k-means zoning, the BFS rail to the coast, "no REST node". Later rulings and the DR replaced all of these.
2. The data contract is split three ways (recorder `city_layout.json`, planner JSON, `city.json`), and the building id is both `key` (3.1, 2.3) and `(ci, key)` (3.2).
3. The §12 checks cannot run on Godot captures, which is what D8 requires, because they need Cycles passes. Several checks are cited from sections that do not contain them. The golden-plates section that D8 asks for does not exist.
4. Several numbers contradict each other: the water z, the day luma target, the Meridian keep footprint, the HQ LOD distances against the rescaled HQ cameras, and the absolute `deck_z` and `z_cut` against the terrain lift.
5. The Q9 variance presets differ between DECISIONS.md and spec 3.5b, and LOW variance can fail the composition checks. The seed derivation (3.5 rule 1 against the `art_seeds` export) is not defined consistently.

Severity ranking is as I read the sources. Rows marked (Q) need a designer or art-director ruling.
