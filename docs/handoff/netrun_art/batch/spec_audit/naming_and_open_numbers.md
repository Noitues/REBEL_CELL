# Audit, scope B: naming, stale names, open numbers N1-N5

Nothing here was rendered or run. Findings come only from the supplied text and grep output. Grep output carries file names only, so rows cite NOTES.md/DESIGN.md with the corp inferred from content. I could not see Appendix A and have not checked it.

## Summary of the worst problems

1. GDD 8.4c still names Halcyon's final server "The Civic Core". GDD 11.7, the spec and the Halcyon notes say THE PANOPTICON, and the handoff README flags this but nothing amends the GDD yet.
2. All four corps with a 11.7 name carry a second GDD name (Renewal Engine, The Manifest, Civic Core, Commons Array), and Orbital also has "the missile bay". The Solace conflict goes beyond 8.3 and 8.4: GDD lines 714 and 720 give the boss stats under "Renewal Engine".
3. Aurelian has no Central Server name at all. D2 allows a made-up one, but the spec, README and GDD list no entry for it, and "Tethys Deep" vs "Atlantis" is used inconsistently.
4. N1, N3 and N5 are stated as open but are built into normative numbers (the 5.2 band distances, the 11.4 budgets, the 11.1 fog mapping). N4 has defaults but no owner. N2 is closed but still listed.
5. The spec text uses the term "Site" and the stale 8.4/8.4b/8.4c/8.4d "M8-M10" tags. Several names (MAINFRAME, MANIFEST CONTROL, DISPATCH) are used both for shop, landmark and boss.
