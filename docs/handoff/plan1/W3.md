## W3-GRID (city): C4 reachable Sites, C3 Heat preview, R6 / C10 grid view
- **C4:** every Site node says whether it is reachable. A locked node, on hover and on click, names why (the
  prerequisite Site, or the gate) and highlights / pans to that prerequisite. Gate links are drawn. Nodes carry a
  short label. No DECRYPTED stamp on a "Not reachable yet" node. A "next reachable" cue (the orange ring the text
  mentions must actually show).
- **C3:** the Heat delta shows **before** acting on Sites, Racks and the flatline warning (from the same Heat rule the
  action uses), and a warning when the delta would cross a raid threshold. Heat Scrub states why it is unavailable.
- **R6 / C10:** GRID VIEW shows the active netrun path and its target; next-node choices are removed there (route view
  only).
- Tests: reachable flag = the rule's reachability for seeded campaigns; previewed Heat delta = the Heat after the
  action.

## W3-ROUTE (city): C7 + 7A route map, R5 static part
- A "pick a node" prompt and an explicit confirm (click selects + shows info; the prompt names Enter / the confirm
  button).
- Node types differ by **shape**, not colour only; the node numbers and the TARGET marker are explained (map key /
  tooltip). All links drawn, including RACK / SHOP branches.
- **7A:** HP recovery and carry-over between nodes visible on the route (what HP you arrive with; where you heal).
- The AT LARGE stamp no longer hides max HP.
- **R5 (static):** nodes drawn on the route, readable; the hover "animate out to its building" part is queued for the
  animation pass (DECISIONS ruling 7).
- Tests: shown carry-over HP = the run state's HP after each node for a seeded route.
