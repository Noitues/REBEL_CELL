## W2-A1: the precision tag (combat)
- A **PERFECT / GOOD / WEAK** tag on each pointer (yours and the enemy's) and in the preview. It updates live as cards,
  nudges and spins are queued or hovered, so the tier shown is the tier SEND IT will resolve. A NULL landing says NULL.
- It is a **named element** (PT-002a step 12: "what is the enemy precision tag?"): its tooltip names it and says what
  each tier does (PERFECT = the full effect / the hook, GOOD = …, WEAK = half), and for the enemy that it shows where
  the needle lands **after this play** (W1-R1).
- V1 item 6: a nudge or spin that moves a pointer changes the tag on the pointer itself, not only in a side note.
- Readable at 1.0 and 2.0 and in high contrast, with a non-colour cue (the word itself).
- Test: tier shown = tier resolved, for seeds × hovered actions × 0 / 1 / 2 prior plays (extend
  `test_w1_tag_preview.gd`).
