## W4-PROMPTS (screens): D-UX2, D-UX3, D-UX4
- **One button look** for every input prompt: the same chip / plate on every screen, only the glyph text differs
  ("[ESC]", "[ENTER]", "[Q]"). One shared kit helper produces it; screens stop drawing their own prompt styles.
  Glyphs come from the action's current keyboard binding (InputMap), not literals.
- **D-UX3:** a Menu button at the top left, left of the Heat widget, on every screen that has the top bar; it opens
  the same pause / menu as Esc.
- **D-UX4:** clicking outside an open menu closes it (menus only — not dialogs, events, confirms or gameplay).
- Tests: every prompt on the covered screens uses the shared helper (scan); the glyph = the InputMap binding; an
  outside click closes a menu and does not close a dialog.

## W4-REWARDS (screens + rules check): D-UX1, F12
- After a fight (and any other reward source using the loot page), **one rewards screen** lists every reward gained
  (Schematics, card pick, Firmware, Daemon, …), Slay the Spire style. Click a reward row to pick from it / take it;
  taken rows mark as taken; SKIP on a pick skips only that pick (F12 by design); PROCEED leaves with a confirm if
  rewards are left untaken.
- The rewards granted are exactly the resolver's payout (no change to what is granted); test: rows = the payout for
  seeded fights, and taking / skipping each row gives the same end state as the old flow.
- Keep the LOOT title sticker as the payout's source (LOOT-02). Keyboard: arrows move between rows, Enter opens.
