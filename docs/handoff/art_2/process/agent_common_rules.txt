LONG JOBS AND SHARING THE MACHINE (added 2026-10-05 after interrupted waits)
- Anything that can take over ~5 minutes (capture matrices, test runs) runs with the Bash tool's
  run_in_background and is checked later by reading its log. Never block on it with a foreground
  `until grep ...; do sleep` loop or `tail -f`: those die when the tool call is interrupted (an incoming
  orchestrator message or a timeout) and the loop is left running as an orphan.
- At most ONE waiter per job. Before starting a new wait, end your old one (by its PID). Before hand-back,
  kill every leftover waiter and helper you started.
- Windowed captures: at most 2 Godot windows at once while other agents are working (-j 2), so the
  machine stays responsive for everyone's tests.
- An interrupted tool call is not an error: re-read your log or output file to see where the job stands,
  and carry on. Do not restart a job that is still running.

BATCH GODOT LAUNCHES (designer 2026-10-05)
- Each Godot launch costs ~6 s of boot (+ ~9 s for an import with nothing new). Batch work into as few
  launches as possible:
  - Tests: run every script you need in ONE gt.sh call (it takes a list), not one call per script; only
    re-run the scripts that failed.
  - Captures: ONE windowed launch per capture session that walks a list of screens / states / demos
    (e.g. tools/visual_qa/review_pack.tscn `--screens=a,b,c`, the storyboard, or your own lab scene that
    steps through every state and writes a frame per state), not one launch per screenshot.
  - Import only after you add or rename files / class_names or after `git merge main`, not before every run.
- Do not keep a long-lived Godot "server" between edits: changed scripts need a fresh process anyway, and
  shared static state leaks between runs.

MACHINE RULES
- NEVER run `python -` (it hangs on stdin, even with an empty heredoc). Write scripts to files with the Write tool and
  run `python file.py`. Set PYTHONIOENCODING=utf-8 when printing non-ASCII.
- Never pipe Godot output: redirect to a file under your own %TEMP%\a2<letter>\ and wrap the command in `timeout`
  (a -s script that fails to parse never quits).
- Windowed Godot ONLY via `python tools/run_windowed.py --log <file> -- <godot args>` from YOUR worktree (never the
  main checkout, never a bare windowed godot: it steals the designer's focus and plays sound). Redirect APPDATA to your
  own temp folder. `mkdir` the Movie Maker frame folder first. Grep the log for ERROR. Headless has no
  RenderingDevice: verify every visible change windowed and READ the frames.
- Kill only PIDs you started. Never `taskkill /IM godot.exe`.
- DISK: captures at 800x450 or crops; delete them once read. `df -h /c` before big captures; under 5 GB free, stop and
  say so. Delete the rebel_cell_tests_* folders in %TEMP% that your runs create. Before hand-back delete your
  %TEMP%\a2<letter>\ folder except your report.
- Bash heredocs break on apostrophes and halve backslashes: write patch scripts with the Write tool.
- .tres union merges: load_steps = sub_resources + ext_resources + 1.
- `git commit -F .git/MERGE_MSG` keeps the "# Conflicts:" lines: strip them.

Report per item: done / not done, the test name(s), any call you made and why, any file outside your area you touched
(smallest change), the fast-tier + own-test results, smoke and validate results, and your final commit hash.
