MACHINE RULES
- NEVER run `python -` (it hangs on stdin, even with an empty heredoc). Write scripts to files with the Write tool and
  run `python file.py`. Set PYTHONIOENCODING=utf-8 when printing non-ASCII.
- Never pipe Godot output: redirect to a file under your own %TEMP%\a0<letter>\ and wrap the command in `timeout`
  (a -s script that fails to parse never quits).
- Windowed Godot ONLY via `python tools/run_windowed.py --log <file> -- <godot args>` from YOUR worktree (never the
  main checkout, never a bare windowed godot: it steals the designer's focus and plays sound). Redirect APPDATA to your
  own temp folder. `mkdir` the Movie Maker frame folder first. Grep the log for ERROR. Headless has no
  RenderingDevice: verify every visible change windowed and READ the frames.
- Kill only PIDs you started. Never `taskkill /IM godot.exe`.
- DISK: captures at 800x450 or crops; delete them once read. `df -h /c` before big captures; under 5 GB free, stop and
  say so. Delete the rebel_cell_tests_* folders in %TEMP% that your runs create. Before hand-back delete your
  %TEMP%\a0<letter>\ folder except your report.
- Bash heredocs break on apostrophes and halve backslashes: write patch scripts with the Write tool.
- .tres union merges: load_steps = sub_resources + ext_resources + 1.
- `git commit -F .git/MERGE_MSG` keeps the "# Conflicts:" lines: strip them.
