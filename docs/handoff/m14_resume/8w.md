## Gotchas
- The worktree guard refuses any compound command with git in it (loops, `&&` chains with git show): run plain
  single git commands.
- Bash heredocs halve backslashes. Write patch scripts with the Write tool.
- `make_hq_compounds.py` hashes every pipeline file. Any edit to the spec, driver, validator or vendor makes all
  five manifests stale. Rebuild all (about 5 min), or rebuild `rebel_cell` and then the rest with `--no-build` after
  their scratch builds exist in `%TEMP%\a8w\hq_compound_build\`.
- `validate_hq_compounds.check` returns early once any error exists, so a failing corp hides later ones.
- `CityView3D._place_landmark` only runs when it can render. Headless has no 3D: test the pure maths.
