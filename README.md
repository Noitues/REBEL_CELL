- Architecture: `docs/TECH_SPEC.md`

## Quick start
1. Install Godot 4.3.
2. `godot --headless --path . -s tools/schema_smoke_test.gd` should print
   `SCHEMA SMOKE TEST: PASS`.
3. Start with milestone M0 in `docs/MILESTONES.md`.
