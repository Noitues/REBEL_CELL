# H7 Bastion raid lab

A playable Godot prototype of the H7 Bastion raid rules (design lab round 7). One leg of 3 raids, five seeded legs to
pick from. A design tool, not part of the game: nothing outside `tools/raid_lab_h7/` is touched.

## Run it

- Play: open `res://tools/raid_lab_h7/raid_lab_h7.tscn` and run the scene (1280x720, text 1.0, mouse and keyboard).
  Windowed runs from a script go through `python tools/run_windowed.py` only.
- Parity check (headless): `godot --headless --path . -s res://tools/raid_lab_h7/parity_check.gd`
- Flow check (headless, model rules and a full play of every leg): `-s res://tools/raid_lab_h7/flow_check.gd`
- Captures: `python tools/run_windowed.py --log <log> -- --resolution 1280x720 res://tools/raid_lab_h7/raid_lab_h7.tscn -- --shots=<abs dir>`
  auto-plays leg 0's planned line and saves a PNG per state. Optional `--leg=N --nobuy` plays leg N with no purchases
  (shows lost nodes, footholds and survivors).

## How to play

1. Leg view: pick a leg (1-5), read the telegraphed raids (Heat, netruns, threats with traits, survivors drawn ghosted;
   two raids ahead while the PROXY holds, else one), then enter the first visit.
2. Visit: click a shop piece, then a held node to buy and place it (at most 2 per visit, within the bank, Z or UNDO
   before START). Click the crew token, then a node to station it (only while the SAFEHOUSE holds; +2 per shot from
   its node). The right column forecasts this raid and the remaining telegraphed raids with this fortress and no more
   buys: clean, lost nodes, net, bank after. The map shows the fixed cobalt routes and per-node tags (HOLDS,
   SCUFFED -N, DOWN, TAKEN). The corp-adaptation chip shows your most-invested piece, the trait, and the threat that
   gains it. START RAID (Enter).
3. Raid: a hands-off playout of the resolver's step log, two beats per step (threats move, then shots with numbered
   badges and damage numbers), 1 s per beat at 1x. Controls: 1x / 2x / 4x / SKIP.
4. Aftermath: CLEAN / HOLDS / BREACHED stamp, net box (salvage x kills + clean bonus - patch = net), income by job
   (base + Vault + Relay), bank arithmetic, node marks, survivors, NEXT VISIT.
5. Leg record: bank line, CLEAN shields, per-raid table.

## What is ported

Source of truth is `tools/raid_concepts/` (python). Port, all deterministic `RefCounted` GDScript, no randomness:

| GDScript | Python |
| --- | --- |
| `h7_sim.gd` (`H7Sim.run`) | `sim.py` `run()` with the `h7_campaign.RULE` toggles: fixed_routes, avoid_home, tiebreak weakest, ice_blocks, no_cascade, crew_flat; threat traits ARMORED / PLATED / FROSTPROOF / BLIND; the Lockdown link freeze; `start_taken`; halves away from zero (all damage is whole numbers here) |
| `h7_campaign.gd` | `h7_campaign.py` `invested`, `roster_for`, `raid_result`, `settle` (plus a `forecast` chain for the UI) |
| `h7_state.gd`, `h7_settle.gd`, `h7_result.gd` | `State`, the settle outputs, `Result` |
| `h7_data.gd` | constants and tables (costs, guns, threats, nodes, links, income, Heat and netrun labels) |

Not ported (not needed by these toggles): jam, circuit, barriers, target_lock, decoy_radius, auditor_hunts, plating.
The view is `raid_lab_h7.gd` (placeholder `_draw()` visuals, glyphs in `h7_glyphs.gd`); `h7_lab_model.gd` holds the play
state and only calls the rules. The 5 seeded legs are `data/h7_golden.json` (a copy of the python golden's `legs`).

## Findings and known gaps

- Python quirk mirrored for parity: when two survivors of the same type share an id (for example two `COLLECTOR#3`
  entering raid 3), the python `T` dict keeps one entry, so only one fights while the roster lists both. The port does
  the same, and the lab draws only the fighters. Worth a rules decision (unique survivor ids) before the real build.
- No golden case reaches a breach (home at 0); the breach branch of `settle` is ported but not covered by parity.
- Placeholder vector visuals: threat chips are lettered hexes, piece and job glyphs are simple primitives, no animation
  polish beyond the beat playout. No sound, no save, no text scale or gamepad (out of scope).
- Forecast rosters for later raids assume no further buys and the crew staying on its node (falls back to the
  SAFEHOUSE, then none).
